# LA County Maximum Statutory Abundance Model

A reproducible scenario-modeling project that estimates how Los Angeles County could change through 2045 under California's most aggressive *legally plausible* pro-growth, supply-side reforms short of a constitutional amendment.

This is **not** a YIMBY brief. The model is deliberately skeptical, separates **legal capacity** from **delivered housing** via a five-gate funnel (legal → entitled → permitted → completed → energized → occupied), accounts for latent-demand absorption of new supply, includes utility/labor/capital constraints, and tracks fiscal feedback into infrastructure reinvestment. Outputs cover housing, rents, population, income, homelessness pressure, business formation, public finance, and legal/implementation risk across 6 scenarios × 3 utility variants × 3 fiscal-capture variants (54 runs), plus 18-parameter OAT sensitivity tornados.

## Quick start

```bash
cd la-county-maximum-statutory-abundance-model
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
python -m src.run_model
pytest tests/
```

The full run (all 54 scenarios + sensitivity + charts + reform menu) completes in under 5 seconds.

## Model architecture in one paragraph

Annual time-step simulation, 2026-2045. Each year, each scenario passes through 13 modules in sequence: legal capacity → entitlements → permits → completions → energization → occupation → housing cost → population → income → homelessness pressure → business formation → fiscal feedback → risk scoring. Cross-module feedbacks lag one year (no within-year iteration). The funnel from legal to occupied has explicit 5-year permit-to-completion lag distributions, utility-lag distributions, construction-labor capacity caps, and infrastructure-funding feedback into next year's utility capacity. Six scenarios encode different reform packages. Three utility variants encode different LADWP/SCE execution. Three fiscal-capture variants encode different infrastructure-reinvestment regimes. All parameters live in editable JSON.

## Customization

Edit parameters in `data/scenario_parameters.json` — every key is documented in the JSON `_meta` field. Re-run `python -m src.run_model`. CSV outputs and charts regenerate.

To add a new scenario: append to the `scenarios` block with override values, register in `src/scenarios.py:central_combinations()` for the headline charts, re-run.

To run a custom sensitivity: edit `sensitivity_parameters` in the JSON and re-run.

## What this model is and is not

**Is.** A transparent, parameter-driven scenario tool for thinking about *which* constraints bind LA County's housing future under various assumptions about legal authority, utility execution, capital markets, fiscal plumbing, and political durability. Reasonably reliable in showing relative differences between scenarios.

**Is not.** A forecast. A general-equilibrium economic model. A neighborhood-level or city-level projection. A Monte Carlo over macro shocks. A substitute for parcel-level feasibility analysis.

**Single most defensible takeaway from running the model.** Legal authority is the easiest of the binding constraints to fix, and the least determinative of outcomes once fixed. California can pass the Maximum Statutory Abundance package and still fail to build if utilities, HCD enforcement, construction labor, and fiscal plumbing are not also addressed.

## Sources strategy

User-provided 2024 baseline values (housing units, permits, rents, home values, household counts, persons-per-household, income, employment, payroll) are used as authoritative anchors. Source *types* (Census QuickFacts, ACS 5-yr, HCD APR, Census CBP, ULI 2023, Colburn-Aldern 2022, Hsieh-Moretti 2019, Combes-Gobillon 2015, Glaeser-Gyourko 2018) are cited by name. The model does not attempt to fetch live URLs or pretend to access HCD APR microdata it cannot verify. Several utility-execution parameters (LADWP transformer queue depth, current SCE interconnection backlog) are flagged as `SOURCE_NEEDED` because reliable public data does not exist; conservative estimates are used and labeled as *weak* evidence.

All elasticities and parameter values are tagged with evidence strength (strong / medium / weak / speculative) in `data/baseline_assumptions.json`.

## Reproducibility

The full pipeline regenerates from JSON in under 5 seconds. Every parameter is editable. Every output file is reproducible. The model is deterministic — no random seeds, no Monte Carlo noise. A fork of this repository running `python -m src.run_model` should produce byte-identical CSVs.
